# GGML 量化类型与数据结构文档设计

## 目标

新增一篇面向量化初学者的中文文档，系统介绍
`src/ggml-common.h` 中的量化类型、块结构和共享查找表，并通过位级示例帮助读者把
“量化公式”与“结构体中的字节”对应起来。

## 范围

- 新增 `docs/ggml量化类型与数据结构.md`。
- 不修改根目录 `README.md`，也不修改任何源码。
- 覆盖 `ggml-common.h` 中全部 24 个 `block_*` 量化结构和
  `iq1m_scale_t` 联合体。
- 解释文件后半部分 IQ 解码表的角色，但不逐项展开大型常量表。
- 不深入各 CPU/GPU 后端的优化内核，也不对不同模型和硬件上的质量、速度作绝对排名。

## 读者与写作原则

目标读者了解基本 C 语言，但没有量化背景。文档先建立概念，再解释类型家族，最后进入位级布局；第一次出现的术语必须解释。结构体名称、字段名称和公式保持与源码一致，中文说明避免把名义位宽误写成实际平均位宽。

## 章节结构

1. 量化是什么：浮点数、整数码值、scale、偏移以及精度/体积取舍。
2. 阅读头文件前的概念：block、`QK`、`QK_K`、bpw、对称/非对称量化、字段命名和 `static_assert`。
3. 类型家族：
   - 经典 Q：`Q4_0`、`Q4_1`、`Q5_0`、`Q5_1`、`Q8_0`、`Q8_1`；
   - 三值 TQ：`TQ1_0`、`TQ2_0`；
   - K 系列超块：`Q2_K` 至 `Q8_K`；
   - IQ 系列：全部 `IQ1`、`IQ2`、`IQ3`、`IQ4` 结构。
4. 位级示例：
   - `Q4_0` 的 32 个权重、16 个量化字节和 2 字节 scale；
   - `Q4_K` 的 256 个权重、8 个子块、6 位 scale/min 和 4 位码值；
   - `IQ2_XXS` 的 grid 索引、符号索引、局部 scale 和查找表解码。
5. 结构体容量总表：块元素数、结构体字节数、实际 bpw、关键字段和定位。
6. 文件后半部分：跨 C/C++/CUDA/HIP/Metal/SYCL 共用常量表的声明方式和用途。
7. 源码阅读路线与常见误区。

## 准确性约束

- 容量按结构体字段计算，并与头文件中的 `static_assert(sizeof(...))` 对照。
- bpw 使用 `sizeof(block) * 8 / block_element_count` 计算。
- `Q4_0`、`Q4_K` 和 `IQ2_XXS` 的解码公式以
  `src/ggml-quants.c` 中相应 `dequantize_row_*` 实现为准。
- 明确 `Q8_K` 是用于中间量化和点积的内部结构，不能只按名称把它当作普通模型存储格式。
- 明确 IQ 类型通过离散 grid/符号表编码，不能套用所有线性 Q 类型的布局。
